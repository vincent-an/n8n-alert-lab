# Http5xxRatio 🟠 major

5xx 응답 비율 5% 초과가 2분 이상 지속. 사용자 영향이 실제로 발생 중.

## 확인 순서
1. 대시보드 "HTTP 요청 수" 에서 5xx 가 나는 URI 확인
2. 같은 시간대 ERROR 로그(Loki) 의 예외 종류 확인
3. p95 응답시간이 함께 튀었는지 확인 → 튀었다면 리소스 고갈(DB 커넥션, 스레드) 의심

## 대응
- 단일 URI 문제: 해당 기능 차단 또는 롤백
- 전 URI 문제: 인프라(DB, 커넥션 풀, 메모리) 확인 → HikariPending 런북
- 원인 파악 전이라도 영향 범위(요청 수 × 에러율)를 공유 채널에 먼저 알림
