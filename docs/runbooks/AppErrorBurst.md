# AppErrorBurst 🟠 major

5분 내 ERROR 로그 10건 이상. 단발성 버그가 아니라 반복 실패 또는 장애 전파 가능성.

## 확인 순서
1. 대시보드에서 에러가 특정 URI 에 몰려 있는지 확인 (HTTP 요청 수 패널, status 별)
2. error_type 이 db 라면 DB 상태 먼저 확인 (커넥션 풀, 락, 슬로우 쿼리)
3. 최근 배포 여부 확인 → 배포 직후라면 롤백 검토

## 대응
- 특정 엔드포인트 집중: 해당 기능 일시 차단(피처 플래그) 또는 롤백
- DB 원인: HikariPending / DbLockContention 런북 참고
- 외부 연동 실패 전파: 타임아웃·서킷브레이커 설정 확인
